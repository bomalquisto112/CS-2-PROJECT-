# Project Title: Daily Task Checklist

## Project Description:
This is a simple program using Python language that helps students manage their academic tasks and accomplish it on time using checklist.

## Features:
- Displays a menu
- Enter a task
- Remove task
- Displays an angry emoji when the assignment is nearing its due date

## How to Run the Program:
1. Download this repository and a Python-compatible IDE.
2. Open the main Python file.
3. Run the program
4. Follow the menu displayed and choose the option you want
